# Аудит мер по обеспечению безопасности данных
## Проблемные зоны:

### Защита данных
- Все действия с данными пользователей происходят в ручном режиме, в форме редактирования\передачи файлов - отсутствие шифрования  
- Данные в виде файлов хранятся в открытом виде  
- Передача хранение и работа с информацией не контролируется и не отслеживается 
- Работа с конфиденциальными данными и PII не в полной мере отвечает требованиям законодательства РФ  
- Работа с персональными данными

### Доступ к данным:
- Отсутствует многофакторная аутентификация  
- Вся информация (в том числе конфиденциальная) открыта для всех - отсутствует авторизация (RBAC)

### Использование подписанных данных
- Данные не подписаны криптографическим алгоритмом для подтверждения их подлинности и целостности  

### Мониторинг и аудит
- Отсутствуют механизмы мониторинга и аудита по доступу и изменению данных  

### Обучение сотрудников
- У сотрудников отсутствует понимание о важности безопасности данных и соблюдении конфиденциальности  
- Отсутствуют стандарты поведения для работы с данными
